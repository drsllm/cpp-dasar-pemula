BAB 1

Variabel: Kotak Wadah Penyimpan di Memori RAM

Komputer tidak memiliki mata untuk melihat barang, tetapi punya memori RAM untuk menyimpan nilai dalam kotak bernama.

5 Tipe Data Primitif Utama di C++

int
Integer (Bilangan Bulat)

Ukuran: 4 Byte. Contoh: 17, -5, 2024.

double
Double (Pecahan / Desimal)

Ukuran: 8 Byte. Contoh: 3.14159, 87.5, 0.005.

char
Character (1 Karakter Tunggal)

Ukuran: 1 Byte. Diapit petik tunggal: 'A', '9', '#'.

string
String (Kumpulan Teks)

Dinamis. Diapit petik ganda: "Budi Santoso", "Informatika".

bool
Boolean (Kebenaran Logika)

Ukuran: 1 Byte. Hanya 2 nilai: true (1) atau false (0).

          BAB 3
          
Menerima Masukan Data: 'cin' dan 'getline'

          
Jika cout menggunakan panah ke kiri <<, maka cin menggunakan
            panah ke kanan >> karena data diserap dari keyboard masuk ke wadah variabel.

        


        

          

            
Perangkap Umum Pemula di C++!

            

              
⚠️ Kapan menggunakan cin >> vs getline?

              

                1. cin >> x; hanya membaca sampai menemukan spasi pertama. Jika Anda
                mengetik "Budi Santoso", yang tertangkap hanya "Budi"!
              

              

                2. getline(cin, x); membaca SELURUH baris sampai pengguna menekan tombol
                [Enter]. Cocok untuk nama lengkap, alamat, atau kalimat panjang.

          BAB 5
          
Logika dan Percabangan (If - Else If - Else)

          
Komputer mengambil keputusan seperti manusia: "JIKA syarat A terpenuhi, maka lakukan tindakan X, jika
            tidak, lakukan tindakan Y".

        


        

          

            
Operator Perbandingan & Logika:

            

              
> Lebih besar dari

              
< Lebih kecil dari

              
>= Lebih besar sama dengan

              
<= Lebih kecil sama dengan

              
== Sama persis dengan (dua kali '=')

              
!= Tidak sama dengan

              
&& DAN (Kedua syarat harus terpenuhi)

              
|| ATAU (Salah satu syarat cukup)

              
! BUKAN / Kebalikan (NOT)

            


            

              
⚠️ Kesalahan Fatal Pemula: = vs ==

              
= (satu tanda sama dengan) adalah untuk mengisi nilai (assignment).

              
== (dua tanda sama dengan) adalah untuk membandingkan apakah dua nilai
                sama.

            

          


          

            
Simulator Keputusan Kelulusan Siswa

            
Geser nilai ujian dan kehadiran untuk melihat cabang if mana yang dieksekusi!


            

              
              
            


            

              
              
            


            

              
            


            

              
Evaluasi Blok Logika C++:

              
if (nilai >= 85 && kehadiran >= 80) {
    status = "Grade A (Sangat Memuaskan)";
} else if (nilai >= 70 && kehadiran >= 75) {
    status = "Grade B (Baik)";
} else if (nilai >= 60 && kehadiran >= 70) {
    status = "Grade C (Cukup)";
} else {
    status = "Tidak Lulus (Remedial)";

          BAB 6
          
Struktur Data Array Dasar (1 Dimensi)

          
Jika Anda memiliki 5 nilai, Anda tidak perlu membuat variabel nilai1, nilai2, nilai3.... Array
            menyimpannya dalam 1 deret memori!

        


        

          

            
Hukum Utama Array C++:

            

              
HUKUM #1

              

                Indeks SELALU Dimulai dari 0, Bukan 1!
                
Jika array berukuran 5, maka slot indeksnya adalah: [0], [1],
                  [2], [3], dan [4].

              

            


            

              
HUKUM #2

              

                Tipe Data Harus Seragam
                
Jika dideklarasikan int arr[5], maka seluruh elemen di dalamnya harus berupa bilangan
                  bulat.

              

            


            

              
HUKUM #3

              

                Pasangan Ideal: Array dan Perulangan (For Loop)
                
Loop for (int i = 0; i < ukuran; i++) dipakai untuk mengunjungi setiap slot dari awal
                  hingga akhir.

              

            

          


          

            
Visualisasi Kotak Memori Array (Ukuran: 5 Elemen)

            
Klik salah satu slot memori untuk mengubah nilainya:


            

              
            


            

              

                
                
                
              

            


            

              

                Total Elemen
                5
              

              

                Total Nilai (Sum)
                415
              

              

                Rata-rata
                83.00
              

            


            

              
Sintaks Kode Pengisian dan Pembacaan:

              int nilai[5] = {80, 85, 90, 75, 85};
int total = 0;

for (int i = 0; i < 5; i++) {
    cout << "Slot [" << i << "] = " << nilai[i] << endl;
    total += nilai[i];
}
double rata = (double)total / 5;
